Configurar a variável ANDROID_HOME

O ApkWrapper precisa de saber onde está o Android SDK instalado. Configura a variável de ambiente ANDROID_HOME de acordo com o teu sistema operativo.

🪟 Windows

Executa no PowerShell (substitui <teu-nome> pelo teu nome de utilizador):

powershell 
[System.Environment]::SetEnvironmentVariable("ANDROID_HOME", "C:\Users\<teu-nome>\AppData\Local\Android\Sdk", "User")

Fecha e reabre o terminal após executar.

🍎 macOS

Adiciona ao ficheiro ~/.zshrc (ou ~/.bash_profile):

bash 
echo 'export ANDROID_HOME=~/Library/Android/sdk' >> ~/.zshrc
source ~/.zshrc

🐧 Linux

Adiciona ao ficheiro ~/.bashrc:

bash 
echo 'export ANDROID_HOME=~/Android/Sdk' >> ~/.bashrc
source ~/.bashrc

✅ Verificar

bash 
# Windows (PowerShell)
echo $env:ANDROID_HOME

# macOS / Linux
echo $ANDROID_HOME

4

Converter a tua app

📁 Estrutura da tua app web

A pasta da tua app deve ter um index.html na raiz:

minha-app/
├── index.html   ← obrigatório
├── style.css
├── app.js
└── imagens/

🚀 Exemplo básico

bash 
node bin/apkwrapper.js build ./minha-app --name "A Minha App"

O ficheiro .apk é gerado em ./dist/A-Minha-App-v1.0.0.apk.

⚙️ Exemplo completo

bash 
node bin/apkwrapper.js build ./minha-app \
  --name         "A Minha App" \
  --package      com.empresa.minhaapp \
  --version-name 1.2.0 \
  --version-code 3 \
  --icon         ./icone.png \
  --output       ./apks \
  --allow-http

📋 Todas as opções

Opção Descrição Valor padrão
--name Nome da app (aparece no telemóvel) obrigatório —
--package ID único da app (formato: com.empresa.app) com.example.app
--version-name Versão visível (ex: 1.0.0) 1.0.0
--version-code Versão interna — número inteiro que deve aumentar a cada update 1
--icon Caminho para um PNG quadrado (512×512 recomendado) ícone padrão
--output Pasta onde a APK é guardada ./dist
--allow-http Permite ligações HTTP (por padrão só HTTPS é permitido) desativado
--android-sdk Caminho manual para o SDK (alternativa a ANDROID_HOME) —
--verbose Mostra o output completo do Gradle desativado
--keep-project Mantém o projeto Android gerado (útil para abrir no Android Studio) desativado
⏳
A primeira build demora mais. O Gradle descarrega ~200 MB de dependências. As builds seguintes são muito mais rápidas.
5

Instalar a APK no telemóvel

🔌 Opção A — Por USB (via adb)

Com o telemóvel ligado por USB e depuração USB ativada:

bash 
adb install dist/A-Minha-App-v1.0.0.apk

📲 Opção B — Manual (sem cabo)

  1. Copia o ficheiro .apk para o telemóvel (USB, email, Google Drive, etc.)
  2. No telemóvel, vai a Definições → Segurança → Instalar apps desconhecidas e permite a instalação
  3. Abre o ficheiro .apk no telemóvel para instalar
✅
A APK é assinada automaticamente com uma chave de debug gerada na primeira utilização. É suficiente para uso pessoal e testes.

Resolução de problemas

🔴 Android SDK not found

A variável ANDROID_HOME não está definida ou aponta para um caminho errado.

Solução: Volta ao passo 2 e confirma que a variável está corretamente configurada. Alternativamente, passa o caminho diretamente:

node bin/apkwrapper.js build ./app --name "App" --android-sdk C:\Users\nome\AppData\Local\Android\Sdk
🔴 No index.html found

A pasta que indicaste não tem um ficheiro index.html na raiz.

Solução: Confirma que o caminho está correto e que existe um index.html diretamente dentro da pasta (não numa subpasta).

🔴 Invalid package name

O --package fornecido não está no formato correto.

Solução: Usa pelo menos 3 segmentos separados por ponto, todos em minúsculas. Exemplos válidos:

com.empresa.minhaapp   ✓ correto
minhaapp               ✗ faltam segmentos
com.MinhaApp           ✗ maiúsculas não permitidas
🔴 java: command not found

O Java não está instalado ou não está no PATH do sistema.

Solução: Instala o JDK 17 em adoptium.net e reinicia o terminal.

🟡 A build demora muito tempo

É normal na primeira vez — o Gradle descarrega ~200 MB de dependências Android. As builds seguintes usam a cache local e são muito mais rápidas (30–60 segundos).

🟡 A app abre mas não carrega o conteúdo

Se a tua app faz pedidos a servidores HTTP (não HTTPS), são bloqueados por padrão.

Solução: Usa a opção --allow-http na build:

node bin/apkwrapper.js build ./app --name "App" --allow-http
